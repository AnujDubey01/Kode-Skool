# KodeSkool — Frontend

React 18 SPA for the KodeSkool platform. See the [root README](../README.md) for full project documentation.

## Quick Start

```bash
npm install
npm start        # runs on http://localhost:3500
npm run build    # production build
```

## Environment Variables

Create a `.env` file in this folder:

```env
PORT=3500
REACT_APP_BACKEND_URL=https://kode-skool.onrender.com
```
